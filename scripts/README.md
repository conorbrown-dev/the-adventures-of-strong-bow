# Source Download Scripts

The official source documents are intentionally downloaded locally rather than
redistributed inside this starter archive.

Run from the repository root after copying the starter-kit folders:

## PowerShell

```powershell
./scripts/download-curriculum-sources.ps1
```

## Bash

```bash
./scripts/download-curriculum-sources.sh
```

If the XML package URL redirects unexpectedly, open the official
Developers & Publishers page in a browser and download the "CCSS Official
Identifiers and Metadata Project XML Version" package into
`resources/raw/ccssi.zip`.

Do not add third-party curriculum websites to these scripts without first recording
their license and ingest policy in `docs/curriculum/RESOURCE_MANIFEST.md`.
