# Oklahoma K–2 curriculum scope

This catalog begins with Oklahoma and covers Kindergarten through Grade 2. It is a standards-aligned learning library, not a claim that a child has mastered a standard merely by opening an activity. A parent, guardian, or teacher should observe performance, give feedback, and record mastery—especially for speaking, writing, investigation, movement, and collaborative work.

## How to interpret coverage

Every row above has a stable Oklahoma standard identifier and at least one activity template. The system validates that every cataloged standard has an activity and that each template can generate a usable prompt. This is **alignment coverage**, not a replacement for a complete instructional program or a mastery record.

For a homeschool plan, each activity should be paired with:

- a real book, manipulatives, materials, or movement space when the standard calls for them;
- adult observation and a short note or work sample;
- repeated practice when the child is not yet secure; and
- a review check before marking the objective complete.

The current implementation intentionally routes performance tasks to the parent/teacher tools. It avoids pretending that a multiple-choice screen can assess oral language, handwriting, science investigation, artistic performance, health judgment, or physical movement.

## Boundaries and next work

Oklahoma's [academic standards index](https://www.oklahoma.gov/education/services/standards-learning/oklahoma-academic-standards.html) lists additional areas. World languages and personal financial literacy are not represented here as K–2 grade-level catalogs; they have proficiency or graduation-related requirements rather than this K–2 objective structure.

Before presenting this as a full public-school alternative, the product still needs sequenced lesson plans, richer instructional content and books, formative and summative assessments, accommodation and accessibility plans, progress reporting, local homeschool-law review, and ongoing expert review of every standards interpretation. This scope document should be updated whenever Oklahoma publishes a revised standard set or the catalog changes.
