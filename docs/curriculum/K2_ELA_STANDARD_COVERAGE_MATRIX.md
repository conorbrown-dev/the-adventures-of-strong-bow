# K–2 ELA Standard Coverage Matrix

Stage 2 design crosswalk generated from the active standards and reviewed template catalog in the repository. This is an instructional design mapping, not an official standards equivalency determination or production approval.

## Scope and interpretation

The matrix includes all **407 active K–2 ELA standard records**: 25 Common Core broad reporting rows, 199 Common Core assessable leaves, and 183 Oklahoma assessable objectives. Counts by source/grade: Common Core Kindergarten 72; Common Core Grade 1 81; Common Core Grade 2 71; Oklahoma Kindergarten 60; Oklahoma Grade 1 62; Oklahoma Grade 2 61.

- Oklahoma is the primary reporting framework; Common Core is retained as a secondary crosswalk.
- Stable coverage-family skill IDs are proposed by `K2_ELA_INSTRUCTIONAL_PROGRESSION.md`; cumulative families may roll up executable child skills such as vowel-specific CVC decoding. Mappings require qualified content review before production.
- `Reporting rollup` is expected for broad non-leaf standards; their coverage is derived from child skills.
- For a composite standard mapped to several sequential skills, `Instructional stage` is the earliest introduction point; later component skills still follow the progression graph and are not unlocked early by the row label.
- `Assessment/practice only` means a reviewed auto-scored template exists but instruction/guided practice/mastery validity is incomplete.
- `Adult evidence only` means a specific adult task exists but a complete instructional/rubric sequence does not.
- `Placeholder only` identifies Oklahoma's generic standard-paraphrase adult prompt.
- `Misaligned—retire/remap` identifies a verified mismatch between official statement and current content.
