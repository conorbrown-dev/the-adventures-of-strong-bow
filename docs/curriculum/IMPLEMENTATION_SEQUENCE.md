# Recommended Implementation Sequence

## Phase 1 — Foundation

- Download official sources.
- Import all official K–5 Math and ELA standards.
- Add standard browser and coverage report.
- Add schemas, provenance, and validation.
- No gameplay integration is required to prove this phase.

## Phase 2 — Learning engine

- Deterministic question templates and generation.
- Answer evaluation.
- Attempt event recording.
- Mastery and spaced review.
- Strand-aware diagnostic.
- Unit and randomized generator tests.

## Phase 3 — Molly-first vertical slice

Build high-quality coverage for K–2 only, starting with the skills most likely to
matter immediately:

- phonological awareness;
- letter names and sounds;
- CVC blending and segmenting;
- vowels/consonants;
- number recognition and counting;
- comparing quantities;
- addition/subtraction foundations;
- Grade 1 arithmetic;
- Grade 2 place value and arithmetic.

Integrate these with Fossil Digging first because its slower pace supports
instruction and corrective feedback.

## Phase 4 — Other game modes

- Dragon Adventure for collected word/number gear.
- Space Shooter for already-introduced recognition and fluency.
- Keep new instruction out of high-pressure action sequences.
- Add boss/story questions for comprehension and multi-step work.

## Phase 5 — Grade 3–5 expansion

Expand by domain and keep the coverage report honest. A standard is not covered
until at least one reviewed, validated template exists. Prefer multiple item forms
before marking a standard assessment-ready.

## Definition of first useful release

The first useful release does not need complete K–5 question coverage. It should:

- contain the complete K–5 standards catalog;
- accurately diagnose and teach K–1 foundational reading and math;
- begin Grade 2 where demonstrated;
- track mastery and review;
- report exactly what is and is not covered.
